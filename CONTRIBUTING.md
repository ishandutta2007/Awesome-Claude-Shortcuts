# Contributing to Awesome Claude Shortcuts

First off, thanks for taking the time to contribute! Contributions are what make the open-source community such an amazing place to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
If you find a bug in one of the shortcuts or notice that an internal command has changed, please open an issue.

### Suggesting Enhancements
Got a great idea for a new shortcut or a better way to organize the library? Open an issue with the "enhancement" label.

### Pull Requests
1. Fork the Project
2. Create your Feature Branch (`git checkout -b feature/AmazingFeature`)
3. Commit your Changes (`git commit -m 'Add some AmazingFeature'`)
4. Push to the Branch (`git push origin feature/AmazingFeature`)
5. Open a Pull Request

## Style Guide
- Keep the shortcuts organized in the table.
- Provide a clear description and primary use case for each command.
- Ensure the formatting matches the existing style.

Join the conversation and stay updated on [how-to-ai.guide](https://how-to-ai.guide).
